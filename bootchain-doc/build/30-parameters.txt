== Параметры загрузки altboot

*altboot* получает параметры загрузки через /proc/cmdline так же, как это
делал link:https://www.altlinux.org/Propagator[пропагатор] и поддерживает
их аналогичным образом. В *altboot* нет аналога параметра *propagator-debug*,
поскольку в самом link:https://www.altlinux.org/Make-initrd[make-initrd] есть
параметры *rdshell* и *stop=runinit* для получения аварийной консоли до перехода
в stage2. В *altboot* нет аналога для параметра *testing*, но есть возможность
перенаправлять отладочный вывод, в том числе, на */dev/console* или
*/dev/ttyprintk*. Все остальные параметры так или иначе поддерживаются:

* *automatic* (строка) — основной накопитель
  _<<_аргументы_параметра_automatic,аргументов пропагатора и altboot>>_;
* *hash* (строка) — хэш-сумма сквоша второй стадии загрузки или целого
  ISO-образа, посчитанная по алгоритму SHA-256 (в altboot можно использовать
  и другие варианты хэша с некоторыми синтаксическими добавками, см. детали
  в описании «шага» _<<_checksum>>_);
* *live* (флаг) — помечает загружаемую систему как LiveCD, что допускает
  наложение _<<_read_only_слои_livecd,read-only слоёв LiveCD>>_ и влияет
  на вывод финальных сообщений в журнал;
* *live_rw* (флаг) — теперь внутренне включает флаг «live» (см. выше) и
  допускает использование _<<_постоянное_хранилище_сеансов_livecd,перезаписываемого
  раздела для хранения сеансов LiveCD>>_ вместо tmpfs;
* *lowmem* (флаг) — включает режим экономии памяти, монтируя образ
  непосредственно с носителя без предварительной загрузки в ОЗУ,
  не оказывает влияния только на методы загрузки http и ftp, поскольку
  в их случае образ всегда загружается в ОЗУ;
* *profile* (строка) — профиль загрузки с поддержкой
  _<<_read_only_слои_livecd,read-only слоёв LiveCD>>_
  (в altboot по умолчанию profile=default и может работать не только с NFS);
* `propagator-debug` — в пропагаторе давал промежуточный shell перед переходом
  из stage1 в stage2, в make-initd есть свои аналоги, реализующие данный
  функционал, поэтому в altboot не реализован (см. детали в разделе по
  _<<_отладка,диагностике и отладке>>_);
* *ramdisk_size* (целое, ядерный) — число килобайт, выделяемых ядром для
  устройств /dev/ram<N>, в один из которых будет загружаться сквош второй
  стадии (в altboot этот параметр стал необязательным);
* *rescue* (флаг) — помечает загружаемый образ как «спасательная система»
  (Rescue), что влияет только на вывод финальных сообщений в журнал;
* *stagename* (срока) — название файла сквоша с rootfs второй стадии загрузки
  (т.н. stage2, типичными названиями для ОС Альт являются «altinst», «rescue»
  и «live», которые в
  _<<_совместимость_с_propagator_и_init_bottom,режимe совместимости с пропагатором>>_
  автоматически обеспечивают установку или сброс флагов «live» и «rescue»,
  см. выше);
* `testing` — «мёртвый» параметр, реально ни на что не влиял, поэтому
  в altboot не реализован, в последних версиях пропагатора перенаправлял
  диагностику на /dev/ttyprintk;
* *updatemodules* (строка) — в пропагаторе ранее использовался совместно с дискетами,
  пока они не перестали поддерживаться, в altboot используется для обновления
  «на лету» файловой системы в stage1, что в частности позволяет подгрузить
  недостающие модули ядра и правила udev.

=== Новые параметры bootchain и altboot

Помимо заимствованных «пропагаторных» параметров введено несколько новых.
Подробнее нижеперечисленные параметры описаны в соответствующих разделах.

* *bc_debug* (флаг) — включает режим расширенной диагностики и копирует
  журнал в stage2 rootfs, по умолчанию под именем «/var/log/chaind.log»;
* *bc_test* (строка) — название выполняемого тест-кейса, копирует его
  вместе с журналом в stage2 rootfs, обычно под именем
  «/var/log/BC-TEST.passed»;
* *bootchain* (строка) — список «шагов» bootchain через запятую (для
  совместимости с пропагатором строка должна завершаться этими двумя:
  «fg,altboot»);
* *cifsopts* (строка) — дополнительные опции монтирования SMB-ресурсов,
  используемые всеми «шагами» cifs;
* *console* (строка, ядерный) — определяет терминал для вывода сообщений,
  в altboot влияет на настройку диалогов и вывод журнала;
* `*forensic*` (флаг) — начиная с версии *0.1.6-alt1*, выключает внутренне
  флаг «live_rw», см. выше: его единственный смысл в том, чтобы сделать
  использование этих двух флагов взаимоисключающим, поскольку в специальном
  режиме «forensic» по умолчанию на диски не должно вноситься каких-либо
  изменений;
* `*mediacheck*` (флаг) — начиная с версии *0.1.5-alt32*, для ISO-образов,
  собранных с одноимённой фичей, и подписанных утилитой implantisomd5,
  перед монтированием образа любым методом загрузки, выполняет проверку
  контрольной суммы носителя программой checkisomd5 с индикацией прогресса;
* *noaskuser* (флаг) — отключает диалоги ввода, как и некоторые значения
  параметра console;
* *nolines* (флаг) — запрещает вывод символов псевдографики в диалогах
  ввода/вывода;
* *nfsopts* (строка) — дополнительные опции монтирования NFS-каталогов,
  используемые всеми «шагами» nfs;
* *overlayroot* (строка) — обеспечивает простой синтаксис для закрытия
  на запись имеющейся rootfs.
